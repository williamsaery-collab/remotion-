# Sanitized originals only

The opening accepts dashboard.png here, with login.png, pin.png, violator.png and
camera.png reserved for reviewed app captures. Never put unredacted captures in
public or Git history. Original screenshots must be transferred as files first.
The ProtectedAppScreen component also applies opaque privacy masks at the supplied
576x1280 coordinates, as a second layer of protection.

Before export, verify all personal names, ticket references, credentials, default
PIN hints, and server addresses have been removed from the source image itself.
Keep the original layout, colors, controls and feature content intact.

Current dashboard.png is the actual supplied dashboard after irreversible opaque
redaction of personal details and system status bars. It was inspected visually.
Its original source remains outside the repository and temporary rendering intake
is removed automatically. Dashboard masks are baked into this PNG.
